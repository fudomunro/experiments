# Learning Portuguese 

With help from Thiago

## Getting Started

I went to Duolingo first, as it's what I'm most familiar with.

First day was pretty good. Lots of ads, but made steady progress.

Second day I had several issues with running out of energy or the app crashing near the end of exercises. It was frustrating, so I decided to try something else.

I found Busuu, which was well reviewed. Initially it also had a lot of ads, so I tried out the 7 day premium trial.

Been making steady progress with Busuu, except for one thing. They have a type of exercise that gets graded by other users, so I have to type or speak the answer and wait for feedback. I find this generally very intimidating for anything where I don't know the answer, so several times I've stopped progress when I hit one of these.
