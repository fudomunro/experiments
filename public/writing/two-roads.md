The Two Roads of AI

As it stands, AI-supported development ingests patterns and practices from all over and tries to implement code using them. The code part is getting pretty darn good, but what's next?

## The singularity

(This is the better one, probably)

Agents almost never write code, instead they call functions or otherwise leverage a single corpus of functionality that comprises the best of the best. Maybe this month your sort algorithm is in Go, but next month a faster one is released in Rust, and your application is now using that one. In fact, all applications are now using it.

## The warlords

Applications/platforms become massive, leveraging fewer libraries and implementing any needed code themselves. Because the LLMs can easily write and rewrite it, and we can get better peformance out of the LLMs if we control all the code they have to work with, and you can reduce supply-chain vulnerabilities.
