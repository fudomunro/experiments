**1. What’s the coolest Python application, framework or library you have discovered in 2011 ?**

<div style="background-color: white; margin-top: 1.5em; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px; text-align: justify;">

**[Requests](http://pypi.python.org/pypi/requests).** I've dealt with Python's HTTP handling on numerous occasions, and most times found myself constructing an abstraction layer to deal with it. Requests provides this abstraction layer for pretty much all of my use cases. I'll give an honourable mention to **[Pyramid](http://www.pylonsproject.org/)**, because it allowed me to bring together my current use of Pylons and my past experience with Zope.

<div style="background-color: white; color: #333333; font-family: 'Trebuchet MS', Arial, Helvetica, sans-serif; font-size: 13px; line-height: 20px; margin-top: 1.5em; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px; text-align: justify;">

**2. What new programming technique did you learn in 2011 ?**

<div style="background-color: white; color: #333333; font-family: 'Trebuchet MS', Arial, Helvetica, sans-serif; font-size: 13px; line-height: 20px; margin-top: 1.5em; padding-bottom: 0px; padding-left: 0px; padding-right: 0px; padding-top: 0px; text-align: justify;">

**[Sorting algorithms](http://alecmunro.blogspot.com/2011/09/sorting-out.html) ;).** On a more serious note, I started actually getting benefit out of Scrum, which is not quite a programming technique but definitely help my programming. On a related note, I learned the benefits of continuous deployment, and some of the techniques one can use to support that.

**6. What are the top software, app or lib you wish someone would write in 2012 ?**

<ul>

<li>

A web service mocking library. I've seen some promising signs in this direction, and I have cause to contribute myself to the effort.
</li>

<li>

A self-replicating Python platform, that can deploy itself from device-to-device relatively transparently. I want to be able to say "run code X on instance Y", and not worry about any of the details of preparing Y or moving X to it.
</li>

</ul>
